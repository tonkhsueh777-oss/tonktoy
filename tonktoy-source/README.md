# 图片处理工具

一个可直接部署在 GitHub Pages 的纯前端图片处理工具。

## 功能

- JPG / JPEG、PNG、WebP 上传
- 自由裁切，以及 16:9、4:3、1:1、3:4、9:16 固定比例
- 任意输出宽高与常用尺寸预设
- PS 式编辑视图缩放：50% / 75% / 100% / 125% / 150% / 200% / 300% / 400%
- 固定尺标、可拖参考线、白框吸附与裁切框大小锁定
- 「视图缩放」只放大编辑画面；「原图缩放」才会改变构图中的原图大小
- JPG / WebP 品质压缩
- JPG / PNG / WebP 格式转换
- 自定义下载文件名，或保留原文件名并自动替换副档名
- 图片全程仅在浏览器本机处理，不上传服务器

## V1 暂未包含

- GIF 动图逐帧处理
- 批量处理与 ZIP 下载

直接打开 `index.html` 即可使用；GitHub Pages 可直接从仓库根目录发布。


## MOV 转 MP4

从图片工具顶部的「MOV 转 MP4」进入，或直接打开 `video-converter.html`。选择或拖入 `.mov`，点击「开始转档」，完成后可预览、下载 `.mp4`。

转档在浏览器本机完成，使用随项目附带的 ffmpeg.wasm。首次使用会载入约 31 MB 的核心；H.264/AAC 影片可快速转换封装，其他受支持编码会转为 H.264/AAC。长影片比桌面软件慢，建议输入小于 500 MB；页面拒绝 1 GB 及以上档案，避免浏览器记忆体耗尽。受保护影片或特殊编码可能无法处理。
